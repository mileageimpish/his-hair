# legacy

Read-only reference material from the old WordPress site (https://www.hishairclinic.hk/): the WXR export, theme files, URL list, SEO data and screenshots. Never edit anything here.

Media and database dumps are never committed:

- `legacy/uploads/` (media library) is git-ignored.
- `legacy/db/` (database dumps) is git-ignored.

Both are large, and a dump may contain personal data. Where they are stored is recorded in `CLAUDE.md`.

What has been captured, and anything still missing, is tracked in Linear issue HIS-2.
