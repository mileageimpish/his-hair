Screenshot method: the viewport is stretched to the page height before capture so the theme's scroll-reveal animations complete. Sliders (Slider Revolution) and CSS animations may be caught mid-transition.

## Restoring the large assets

The crawl ran in a cloud container, so the big artefacts are kept on the orphan branch **`legacy-assets`** (Git LFS; see its README): `git fetch origin legacy-assets && git worktree add ../his-hair-assets legacy-assets && cd ../his-hair-assets && git lfs pull`, then extract the tarballs into `legacy/`. `legacy/cache/` is not stored (re-creatable by re-running the scripts, about 25 min for URLs/media plus about 2 h for snapshots).
